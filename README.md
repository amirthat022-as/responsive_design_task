# Responsive Design Tokens & Mobile-First CSS Architecture

## Task completed
- CSS design tokens in `:root`
- Primary colors, typography, spacing and border-radius tokens
- Responsive dashboard grid
- Breakpoints: 320px, 768px, 1024px, 1440px
- Glassmorphism backdrop filter
- Soft shadows and hover transitions
- Dark/light theme variables
- Mobile-first CSS
- No horizontal scrolling on small screens

## Files
- `index.html` — responsive demo page
- `style.css` — complete CSS architecture
- `screenshots/` — responsive demo proof images
- `README.md` — submission notes

## How to run
1. Open `index.html` in a browser.
2. Resize the browser to test 320px, 768px, 1024px and 1440px widths.
3. Upload the project to GitHub.
4. Submit the GitHub repository link and screenshots as proof.
